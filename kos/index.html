Cloud Sync antar Perangkat

Belum dikonfigurasi

Hubungkan KosMan ke server cloud agar data dapat digunakan di Mac, iPhone, dan iPad. Data lokal tetap berjalan saat internet terputus; sinkronisasi dilanjutkan ketika koneksi pulih.

Mode saat ini: penyimpanan lokal. Belum ada data yang dikirim ke cloud.
Setiap perangkat harus memakai URL server, Workspace, dan kunci akses yang sama. Untuk pertama kali, pilih satu arah awal: unggah data lokal atau ambil data cloud.

Keamanan: kunci cloud adalah rahasia bersama, bukan akun per pengguna. Siapa pun yang memiliki kunci dapat mengakses workspace pada server; ID Workspace bukan pengaman. Gunakan HTTPS, jangan bagikan kunci, dan buat backup sebelum mengganti data lokal/cloud.
